# Local Image Studio — إصدار الواجهة 0.3.0

## ما الذي تم تحسينه في هذه النسخة؟
- إعادة تصميم الواجهة بأسلوب داكن حديث، بطاقات مستديرة، تباين أوضح، ومسافات مريحة.
- ترتيب الشاشة إلى أقسام واضحة: وصف الصورة، الوصف السلبي، النموذج، إعدادات الصورة، وفحص الإعدادات.
- إضافة ثلاثة أمثلة جاهزة للوصف لتسهيل البدء.
- عدّاد أحرف للوصف مع حد 1200 حرف.
- حفظ آخر وصف والوصف السلبي وعدد الخطوات وCFG محلياً، مع زر لاستعادة آخر وصف.
- اختيار ملف النموذج مع عرض اسمه الحقيقي إن أمكن وحفظ إذن الوصول إليه.
- إضافة عناصر إعدادات واجهة للأبعاد وSampler وSeed.
- إضافة منزلقات Steps وCFG بدل إدخال الأرقام يدوياً.
- تنفيذ الفحص خارج خيط الواجهة وإظهار تقرير واضح.
- لا توجد صلاحية INTERNET أو صلاحيات شبكة في AndroidManifest.
- بقي دعم ABI على arm64-v8a والحد الأدنى Android 8.0 (API 26).

## حدود هذه النسخة — اقرأ قبل البناء
**هذه النسخة ما زالت واجهة وتجهيزات أولية وليست مولّداً فعلياً للصور.** محرك Stable Diffusion غير مضمّن وغير مربوط. زر «فحص الإعدادات» يتحقق من المدخلات ويعرض تقريراً فقط؛ لا ينشئ صورة.

الأبعاد وSampler وSeed وSteps وCFG معروضة كإعدادات واجهة، لكن لا يستهلكها محرك توليد حالياً. وضع Image-to-Image وInpainting غير منفذين. كما أن اختيار ملف النموذج لا يثبت أن تنسيقه أو بنيته متوافقان.

لم يتم بناء APK أو إجراء اختبار تشغيل على هاتف ضمن بيئة إنشاء هذه الحزمة. لا تعتبر الحزمة إصداراً نهائياً مضموناً.

## متطلبات البناء من سطر الأوامر على Windows
- JDK 17.
- Gradle 8.9 (لتوليد Gradle Wrapper أول مرة).
- Android SDK Command-line Tools.
- Android SDK Platform 35 وBuild Tools 35.0.0.
- Android NDK 27.2.12479018 وCMake 3.22.1.

اضبط مسار SDK حسب مكان تثبيته، مثال:

```bat
set ANDROID_HOME=C:\Android\Sdk
set ANDROID_SDK_ROOT=%ANDROID_HOME%
set PATH=%PATH%;%ANDROID_HOME%\platform-tools;%ANDROID_HOME%\cmdline-tools\latest\bin
```

اقبل التراخيص وثبّت المكونات:

```bat
sdkmanager --licenses
sdkmanager "platform-tools" "platforms;android-35" "build-tools;35.0.0" "ndk;27.2.12479018" "cmake;3.22.1"
```

افتح CMD داخل مجلد المشروع الذي يحتوي على `settings.gradle.kts`، ثم نفّذ أول مرة:

```bat
gradle wrapper --gradle-version 8.9
```

وبعد إنشاء `gradlew.bat`:

```bat
gradlew.bat clean
gradlew.bat assembleDebug
```

ملف APK الناتج عند نجاح البناء:

`app\build\outputs\apk\debug\app-debug.apk`

## دمج محرك التوليد لاحقاً
1. اختيار إصدار ثابت ومحدد من stable-diffusion.cpp ومراجعة ترخيصه واعتمادياته.
2. بناء مكتباته باستخدام Android NDK لـ arm64-v8a وCMake.
3. ربط واجهة JNI بواجهات المحرك الحقيقية؛ لا يكفي وجود ملف JNI تجريبي.
4. تمرير `content://` عبر ContentResolver/ParcelFileDescriptor أو نسخ النموذج بأمان إلى مساحة التطبيق.
5. تنفيذ التحميل والتوليد والإلغاء وتحرير الذاكرة في مهام خلفية.
6. اختبار نموذج SD 1.5 بدقة صغيرة على جهاز فعلي وقياس الذاكرة والحرارة والاستقرار قبل إضافة بقية الأوضاع.

## الخصوصية
التطبيق لا يطلب صلاحية الإنترنت. اختيار النموذج يتم من ملفات الجهاز، ويجب تنزيل النماذج خارج التطبيق ثم استيرادها محلياً. لا توجد حالياً خدمة توليد سحابية.
